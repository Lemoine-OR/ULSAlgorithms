# Scientific References

The list below provides the main publications represented by public strategies.
Individual algorithm pages and source comments contain more
implementation-specific notes.

## Foundational exact methods

- H. M. Wagner and T. M. Whitin (1958), *Dynamic Version of the Economic Lot
  Size Model*, Management Science 5(1), 89-96.
  DOI: https://doi.org/10.1287/mnsc.5.1.89
- W. I. Zangwill (1969), *A Backlogging Model and a Multi-Echelon Model of a
  Dynamic Economic Lot Size Production System--A Network Approach*,
  Management Science 15(9), 506-527.
  DOI: https://doi.org/10.1287/mnsc.15.9.506
- A. Federgruen and M. Tzur (1991), dynamic lot-sizing algorithms with
  improved complexity. DOI: https://doi.org/10.1287/mnsc.37.8.909
- A. Wagelmans, S. Van Hoesel and A. Kolen (1992), *Economic Lot Sizing: An
  O(n log n) Algorithm That Runs in Linear Time in the Wagner-Whitin Case*,
  Operations Research 40(1 supplement), S145-S156.
  DOI: https://doi.org/10.1287/opre.40.1.S145
- A. Aggarwal and J. K. Park (1993), *Improved Algorithms for Economic Lot
  Size Problems*, Operations Research 41(3), 549-571.
  DOI: https://doi.org/10.1287/opre.41.3.549

## Provenance policy

A publication name on a public class is treated as a provenance claim.

When the original program listing is not available and the implementation
reconstructs the published architecture, the documentation states **modern
reconstruction** rather than implying a line-by-line transcription.

The runtime catalog is additionally checked for non-empty provenance metadata
for all 42 public strategies and for normalized DOI values whenever a DOI is
recorded.
