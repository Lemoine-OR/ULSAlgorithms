# Documentation encoding + mathematical formulations fix

This overlay fixes two issues after the v0.22 documentation refactor.

1. Windows PowerShell 5.1 mojibake
   - docs/build-documentation.ps1 is now ASCII-only.
   - non-ASCII punctuation generated by the script uses HTML entities or ASCII.
   - the build now scans generated HTML/CSS/JS for common mojibake markers and fails if any are found.

2. Mathematical formulation pages
   - the four solver-backed formulation pages now display their mathematical model directly with MathJax/LaTeX.
   - the same equations are added to the corresponding generated Doxygen algorithm pages.
   - models are aligned with the actual formulation builders.

No source-code algorithm, public API, version.json or release metadata is changed.
