# Lemoine-OR Algorithms — shared visual identity

This identity is intended for **pure algorithm repositories** maintained under Lemoine-OR.

## Concept

The mark combines three ideas:

1. an **algorithmic path** progressing through decision nodes;
2. a geometric **A-like construction** suggesting “Algorithms” without using text in the icon;
3. an orange transition arc representing state change, optimization and improvement.

The icon deliberately avoids generic AI robots, gears and `</>` code clichés.

## Usage

- **favicon / small square:** icon only;
- **README:** ULSAlgorithms lockup;
- **Doxygen title:** compact ULSAlgorithms lockup;
- **future algorithm repository:** same icon + project-specific wordmark;
- **GitHub social preview:** project-specific 1280×640 image.

Keep clear space around the icon equal to approximately one node diameter.

## Tagline

**Clean. Scientific. Open.**

The tagline is optional and should be used for the Lemoine-OR Algorithms family rather than inside the icon itself.
